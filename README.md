# Flipper-Zero-Toolkit---Base-Project

Toolkit en Python para crear, gestionar y automatizar payloads para Flipper Zero de forma rápida y sencilla.

## Características

* Generador de payloads BadUSB
* Payloads predefinidos listos para usar
* Auto-detección de microSD del Flipper
* Exportación automática de scripts
* Organizador de archivos
* Sistema de logs

## Requisitos

* Python 3.x
* Flipper Zero (opcional)

## Uso

```bash
python main.py
```

## Funcionalidades

### 🔹 Payload personalizado

Genera scripts BadUSB introduciendo comandos manualmente.

### 🔹 WiFi Extractor

Ejemplo educativo que lista perfiles WiFi en Windows.

### 🔹 Abrir Notepad

Payload simple de prueba.

### 🔹 Organizador de archivos

Ordena archivos automáticamente por extensión.

## Logs

Los registros se guardan en:

```
/logs/
```

## Disclaimer

Este proyecto es solo para fines educativos. No utilizar en sistemas sin permiso.
